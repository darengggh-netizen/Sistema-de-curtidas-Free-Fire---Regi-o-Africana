# SISTEMA DE ENVIO DE CAMISAS FREE FIRE

## 👕 Visão Geral

Sistema funcional para enviar camisas (skins de times) do Free Fire via token autenticado.

## 📋 Estrutura

```
.
├── backend_shirts.py        # API Python com autenticação
├── shirts_system.html       # Interface web
└── README_SHIRTS.md         # Documentação
```

## 👕 Camisas Disponíveis

- Flamengo
- Vasco
- Botafogo
- Fluminense
- Santos
- Corinthians
- São Paulo
- Palmeiras
- Cruzeiro
- Atlético Mineiro
- E mais...

## 🚀 Começar

```bash
pip install fastapi uvicorn pyjwt
python backend_shirts.py
```
