# SISTEMA SIMPLES DE ENVIO DE LIKES - FREE FIRE

## 🎯 Visão Geral

Sistema simples e funcional para enviar likes para contas Free Fire na região africana.

## 📋 Estrutura

```
.
├── backend/
│   └── app.py                 # API Python simples
├── frontend/
│   ├── index.html
│   ├── style.css
│   └── script.js
└── README.md
```

## 🚀 Começar

### 1. Backend (Python - FastAPI)

```bash
pip install fastapi uvicorn
```

### 2. Frontend (HTML + JS)

Abra o arquivo `index.html` no navegador.

## 📡 API Endpoints

- `POST /likes/send` - Enviar like
- `GET /likes/history` - Histórico de likes
